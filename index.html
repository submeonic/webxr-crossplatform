LearnQM WebXR Template

A cross-platform WebXR learning template for desktop, Meta Quest, and Apple Vision-style spatial devices. Scroll through the lesson to swap simulations, or enter XR to explore with hand-based locomotion.

Simulation 01

Gesture Locomotion

This template includes a shared WebXR shell, a sticky 3D viewer, desktop fallback navigation, and a thumb-controlled virtual D-pad locomotion system for immersive XR.

On desktop, use WASD or the arrow keys to orbit and dolly around the active simulation target.

Simulation 02

S Orbitals

As the lesson scrolls, the right-side viewer keeps the same renderer, camera, player rig, XR button, and locomotion system. Only the active simulation module changes.

When a new simulation becomes active, the player rig and camera are reset so each section starts from a predictable view.

Simulation 03

P Orbitals

Each visualization is written as a small module with enter(), exit(), update(), and an orbitTarget.

This lets new LearnQM chapters reuse the same WebXR infrastructure while replacing only the educational scene content.
